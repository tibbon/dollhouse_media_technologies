Release Notes

Every version of BlackBox, newest first. Updates are free from the Mac App Store.

1.5.1

2026-10-05

Safer long recordings, and a round of reliability fixes.

  • Recordings cut short by a crash or power loss are repaired automatically the next time BlackBox opens, losing at most about 10 seconds.
  • Long takes start a new file before reaching the 4 GB WAV limit, so every file opens fully in any audio app.
  • The input device list updates when you plug in or unplug an audio interface.
  • Changing a recording setting while recording offers to restart, so the change takes effect right away. Choosing a new folder continues the recording there.
  • Level meters catch short peaks and clips, and are labelled with the channels you are recording.
  • 24-bit, 32-bit and multichannel files use the WAV header that professional audio tools expect. Split-mode files are numbered from channel 1, matching the app.
  • Setup asks before assigning a global shortcut, and running setup again keeps your current settings.
  • Logging out or shutting down is no longer blocked while recording, and BlackBox finishes the file before your Mac sleeps or another app quits it.
  • Stopping no longer hangs after a long session with silence detection on.
  • Fixed channels that could swap after the recorder briefly fell behind.
  • The "Restart Recording" notification button now works, and a "Disabled" minimum free space setting is kept after relaunch.
  • Warning icons in the menu show on macOS 27.

1.5.0

2026-09-21

Localization, accessibility, and reliability improvements.

  • The app is now localizable, with number, file-size, and bitrate values formatted for your region.
  • Recordings no longer clip the moment audio begins — the sound that opens the silence gate is captured from the start.
  • Improved fidelity when saving 16-bit files (dither on conversion).
  • Accessibility: VoiceOver support across onboarding, the level meter, the channel grid, and the menu; Reduce Motion and Dynamic Type are honored.
  • More reliable recovery from disk-write failures and across sleep/wake; recordings now save to the app's own folder by default.

1.2.0

2026-05-08

Reliability and accessibility polish.

  • Settings now opens via the standard ⌘, shortcut from anywhere in the app and inherits macOS's normal Settings window behavior.
  • First-run onboarding correctly remembers your choice of recording folder — no more "Output Directory Unavailable" prompt on second launch when you accepted the default.
  • "Recording Started" notifications appear reliably on the first auto-record-on-launch, instead of being dropped before notification permission was requested.
  • Onboarding accessibility: VoiceOver users can now navigate the recording-mode picker as a single-select group, and step back through completed onboarding steps via the indicator dots.
  • Level-meter VoiceOver readouts are throttled to threshold crossings (Silent / Low / Moderate / Hot / Clipping) instead of streaming a new dB reading every screen tick.
  • Internal cleanups: removed leftover scaffolding code, modernized the build pipeline, hardened the supply chain.

1.1.0

2026-05-07

Reliability and polish across the recording engine.

  • The menu bar icon now pulses while recording so you can see at a glance that capture is live.
  • Onboarding window no longer clips on the recording-mode step and reopens to the foreground if you've dismissed it.
  • Faster app launch — the menu bar appears immediately instead of waiting on a folder probe.
  • Smoother level meters during long sessions.
  • More precise error reporting — failures from the audio engine now surface specific reasons (device unavailable, low disk space, etc.) instead of a generic message.
  • Hardened audio-sample conversion against malformed input from unusual devices — bad samples can no longer freeze the level meter or skew silence detection.
  • Smaller download (~26% reduction).
  • Updated to the latest Rust toolchain and audio dependencies.
